# P2 – Movie Recommendation System Using NLP

Second-year B.Tech AIML mini project.

## Objective
A content-based movie recommendation system using Natural Language Processing, TF-IDF and cosine similarity.

## Technologies
- Python
- Pandas
- Scikit-learn
- TF-IDF Vectorization
- Cosine Similarity
- Google Colab / any Python environment

## Features
- Accepts a movie title
- Converts movie genre and description into TF-IDF vectors
- Calculates cosine similarity
- Displays up to five similar movies
- Handles unknown movie titles
- Supports different capitalization

## Run
Install dependencies:
```bash
pip install pandas scikit-learn
```

Then:
```bash
python movie_recommendation.py
```
